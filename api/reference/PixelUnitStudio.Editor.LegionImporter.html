BuildRigPrefab(string, string, string, string, string, Dictionary<string, string>)

Slices a part sheet that follows the cell layout and saves it as a skeleton prefab. The weapon sheet (48×48, handle at the center) is optional. slotSheets maps slot name (Cloth, Hair, etc.) → a slot sheet with the same cell layout as the body sheet. Each is attached as a child named after the slot under each bone, with sorting value = bone sortBase + slot layer. Empty cells in a slot sheet are skipped.
