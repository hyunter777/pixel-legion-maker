A content pack: a folder of parts, weapons, projectiles and heroes that the catalog takes in (LegionCatalogBuilder). The base product is one pack (LegionBasePack.asset); an add-on is another pack asset in its own folder, so it holds only art and heroes and needs the base product to work. Name add-on art with the type first, as the base product does (axe_frost, helmet_raider), because weapon motions and filters come from the first word. Folders are relative to the folder that holds this asset. When packs are added, removed or their art changes, the catalog rebuilds itself in the editor.
