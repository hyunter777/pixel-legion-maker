ExportSheet(GameObject, string, Dictionary<string, int>, string)

Renders every motion of the rig prefab frame by frame and saves them as a sheet, one motion per row. Given a motionSet (spear, heavy, bow, etc.) it exports that weapon type's motions; left empty it exports the default (sword, axe, blunt) motions. Frames are 64×64 by default (origin: horizontal center, ground 2px from the bottom); if big or long weapons have pixels outside that, all frames are widened to fit (in steps of 8px horizontally and vertically). The origin is at the same spot in every frame, and size and origin are written to the .json.
