Plays custom actions (LegionAction) on a hero: each step's motion in turn, then back to idle (an action ending in death stays down). Saved hero prefabs carry one that references the action library of their save folder; heroes assembled with LegionBuilder get one from Builder.Actions. While an action plays, LegionEvents.returnToIdle waits for the action to finish. Hit and cast events still fire for every step.
