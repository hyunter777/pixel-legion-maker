Pixel Legion Maker API

Namespace PixelUnitStudio.Editor

Classes

LegionAnimation

Builds AnimationClips and an Animator from legion_anims.json, and exports the motions as 64×64 1:1 pixel frame sheets.

LegionCatalogBuilder

Builds the catalog (slots, options, icons, turn art, motion sets) from the art of every content pack in the project (LegionContentPack). The edit screen and save/export use this catalog. It used to be an installer that grafted a hero mode into the existing maker scene, but the edit screen now has all of that, so the maker integration was removed.

LegionEditorScene

Builds the edit screen scene. The screen is drawn in code by LegionEditor at play time, so the scene holds only the camera, event system and editor object.

LegionImporter

Slices the body sheet per rig.json, and builds the mannequin prefab and a preview scene.

LegionPacks

Finds the content packs in the project (LegionContentPack) and resolves their folders. The base product is one pack; add-ons are more packs in their own folders, read after it.
