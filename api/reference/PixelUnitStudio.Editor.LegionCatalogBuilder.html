Builds the catalog (slots, options, icons, turn art, motion sets) from the art of every content pack in the project (LegionContentPack). The edit screen and save/export use this catalog. It used to be an installer that grafted a hero mode into the existing maker scene, but the edit screen now has all of that, so the maker integration was removed.
