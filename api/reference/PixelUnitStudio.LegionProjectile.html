Class LegionProjectile

Flies one projectile from its start point to the target point, calls Arrived when it lands, then removes it. Bows, crossbows, guns and staffs fly the catalog's projectile art (Projectiles/) straight; thrown weapons throw the weapon art itself in an arc. A thrown weapon doesn't rotate its art; it spins by swapping pre-rotated art (turns), so pixels don't break. Hit detection is up to the game. Usually called from the hit event of an attack motion (LegionEvents).
