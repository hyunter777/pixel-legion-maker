# Support and licenses

## Getting help

Start with the [FAQ](faq.md). Questions and bug reports: [GitHub Issues](https://github.com/hyunter777/pixel-legion-maker/issues), or email hyunter@flycat.co.kr.

Please include:

- The Pixel Legion Maker version and your Unity Editor version.
- The render pipeline and input backend you use.
- Steps to reproduce the issue, the expected result and the actual result.
- Relevant Console messages and, when useful, a screenshot.
