# API reference

The <a href="../../api/index.html">generated API reference</a> documents the public C# types and members in the package's two assemblies:

- **PixelUnitStudio.Runtime**: heroes, the builder and recipes, events, actions, projectiles, the catalog and the pixel camera.
- **PixelUnitStudio.Editor**: catalog build, animation build, frame sheet export and content packs.

Start with [Heroes in code](../using-heroes.md) and [Runtime recipes](../recipes.md) for examples. The C# namespace is `PixelUnitStudio`.

The reference is generated from the package's public declarations. The package implementation is not published with this site.
